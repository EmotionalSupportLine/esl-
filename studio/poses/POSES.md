# EmoOwl poses: which owl to use

Every post in a posts file can name a pose: `"pose": "full-moon"`. The name is the file name in this folder, without `.png`. If you leave it out, or the name doesn't exist, the plain logo owl is used.

How to choose: pick the owl whose activity or mood matches the post's one idea. Don't use the same pose twice in one week. Preview sheets are in Tracee's Owl Image Library on her computer.
